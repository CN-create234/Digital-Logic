# 数字逻辑电路考研复习讲义

## 第一章 数字逻辑基础

### 1.1 数制

**进位计数制**：按进位方式计数的数制，其基本要素包括基数（R）和位权（R^i）。任一R进制数可表示为各位数码与位权乘积之和。

| 数制 | 基数 | 数码 | 位权 | 进位规则 |
|------|------|------|------|----------|
| 二进制 | 2 | 0,1 | 2^i | 逢二进一 |
| 八进制 | 8 | 0~7 | 8^i | 逢八进一 |
| 十进制 | 10 | 0~9 | 10^i | 逢十进一 |
| 十六进制 | 16 | 0~9，A~F | 16^i | 逢十六进一 |

**不同数制间的转换**：

**R进制→十进制**：按权展开相加。例如：`(1011.11)₂ = 1×2³+0×2²+1×2¹+1×2⁰+1×2⁻¹+1×2⁻² = 11.75`

**十进制→R进制**：整数部分除以R取余（倒序），小数部分乘以R取整（顺序）。

**二进制↔八进制**：三位二进制对应一位八进制（整数部分从右向左，小数部分从左向右分组）。**二进制↔十六进制**：四位二进制对应一位十六进制。

### 1.2 常用编码

| 编码名称 | 特点与应用 |
|----------|------------|
| **8421 BCD码** | 用4位二进制表示1位十进制数，0000~1001对应0~9，最常用 |
| **余3码** | 8421码加3得到，具有自补性 |
| **格雷码** | 相邻两个码之间仅1位不同，常用于减少转换误差 |
| **奇偶校验码** | 在数据位后附加校验位，使1的个数为奇数（奇校验）或偶数（偶校验），用于检错 |
| **ASCII码** | 字符数字码，7位表示128个字符 |

### 1.3 逻辑代数

**基本逻辑运算**：

| 运算 | 表达式 | 真值表关键 | 逻辑符号 |
|------|--------|------------|----------|
| **与（AND）** | Y = A·B | 全1出1 |  |
| **或（OR）** | Y = A+B | 有1出1 |  |
| **非（NOT）** | Y = \bar{A} | 取反 |  |

**复合逻辑运算**：与非（NAND）、或非（NOR）、异或（XOR）、同或（XNOR）。

- **异或**：Y = A⊕B = A·\bar{B} + \bar{A}·B，相同为0，不同为1
- **同或**：Y = A⊙B = A·B + \bar{A}·\bar{B}，相同为1，不同为0；异或与同或互为反

**逻辑代数的基本定律与规则**：

| 定律名称 | 公式 |
|----------|------|
| 0-1律 | A·0=0，A+1=1 |
| 同一律 | A·1=A，A+0=A |
| 互补律 | A·\bar{A}=0，A+\bar{A}=1 |
| 交换律 | A·B=B·A，A+B=B+A |
| 结合律 | (A·B)·C=A·(B·C)，(A+B)+C=A+(B+C) |
| 分配律 | A·(B+C)=A·B+A·C，A+B·C=(A+B)·(A+C) |
| 吸收律 | A·(A+B)=A，A+A·B=A |
| 德摩根律（反演律） | \overline{A·B} = \bar{A}+\bar{B}，\overline{A+B} = \bar{A}·\bar{B} |

**反演规则**：将逻辑函数F中的“·”与“+”互换、“0”与“1”互换、原变量与反变量互换，得到`\bar{F}`。**对偶规则**：不进行变量取反，其余同反演。

### 1.4 逻辑函数的表示与化简

**逻辑函数的五种表示方法**（能相互转换）：
- 真值表（最直观）
- 逻辑表达式（最常用）
- 逻辑图
- 卡诺图
- 波形图

**最小项**：包含全部n个变量的乘积项，每个变量以原变量或反变量出现一次。

**最大项**：包含全部n个变量的和项，每个变量以原变量或反变量出现一次。

**标准与或式**：最小项之和的形式。标准或与式：最大项之积的形式。

**逻辑函数的化简方法**：

**（1）公式化简法**：运用基本定律和公式进行代数变换。常用技巧：并项法（`A\bar{B}+AB = A`）、吸收法（`A+AB = A`）、消项法（`AB+\bar{A}C+BC = AB+\bar{A}C`）。

**（2）卡诺图化简法**：

卡诺图是将真值表按循环码排列得到的方格图。n个变量对应2^n个方格，相邻方格（含上下、左右、对称位置）只有一个变量不同。用圈“1”的方法合并相邻最小项，圈越大越好（2^k个1），遵循“圈尽量大、圈尽量少”的原则。

**（3）具有无关项的逻辑函数化简**：
在逻辑函数中，某些变量的取值组合永远不会出现（约束项），或出现时输出可任意（任意项），统称为无关项。化简时可将无关项根据需要视为0或1，以得到更简的表达式。


## 第二章 逻辑门电路

### 2.1 门电路概述

门电路是实现基本逻辑运算和复合逻辑运算的电子电路，是构成数字系统的基本单元。数字电路采用**高电平**和**低电平**表示逻辑1和0。

**正逻辑与负逻辑**：
- 正逻辑：高电平=1，低电平=0
- 负逻辑：高电平=0，低电平=1（本讲义默认采用正逻辑）

### 2.2 TTL门电路

TTL（Transistor-Transistor Logic）是双极型晶体管逻辑电路。

**TTL与非门**：多发射极晶体管实现与功能，推挽输出级提供驱动能力。

**TTL主要电气特性**：
- **电压传输特性**：输出电压随输入电压变化的曲线
- **输入特性**：输入电流与输入电压的关系
- **输出特性**：输出电流与输出电压的关系
- **噪声容限**：保证逻辑功能正确时允许的最大噪声幅度
- **扇出系数**：可驱动同类门的最大数量

**常用TTL门类型**：与非门、或非门、与或非门、异或门、三态门（TSL）、集电极开路门（OC门）。

**OC门**：输出端可并联（线与），需外接上拉电阻，适用于总线结构。

**三态门（TSL）**：除高电平、低电平外，还有高阻态（输出悬空），使能控制时可实现多路数据共享总线。

### 2.3 CMOS门电路

CMOS（Complementary MOS）由互补的NMOS和PMOS管组成。

**CMOS反相器**：由PMOS和NMOS构成，输入为0时PMOS导通、NMOS截止，输出为1；输入为1时相反。

**CMOS门电路特点**：功耗极低（静态时几乎没有电流）、抗干扰能力强、电源电压范围宽。速度比TTL稍慢，但随工艺进步已得到改善。

**CMOS数字集成电路的特点**：
1. 静态功耗极低
2. 电源电压范围宽（3~18V）
3. 输入阻抗极高
4. 输出驱动能力较弱（可通过缓冲级改善）

**使用注意事项**：未使用的输入端不能悬空（易引入干扰），应先接高电平或低电平。

### 2.4 TTL与CMOS的接口

两种电路混用时需注意电平匹配：TTL输出高电平（约3.6V）可驱动CMOS输入端，但CMOS输出高电平（接近VDD）可能超出TTL输入范围，需加电平转换电路。


## 第三章 组合逻辑电路

### 3.1 组合逻辑电路的特点

组合逻辑电路在任一时刻的输出状态**只取决于该时刻的输入状态**，与电路原来的状态无关。即：**无记忆功能**，不含存储单元。输出与输入之间存在确定的逻辑函数关系。

### 3.2 组合逻辑电路的分析

**分析步骤**：
1. 从输入端开始，逐级写出各门输出的逻辑表达式
2. 化简表达式
3. 由表达式列出真值表
4. 分析电路逻辑功能

### 3.3 组合逻辑电路的设计

**设计步骤**：
1. 根据功能要求定义输入/输出变量
2. 列出真值表
3. 由真值表写出逻辑表达式并化简（常用卡诺图）
4. 根据化简结果画出逻辑图
5. 选用合适的逻辑门（必要时做与非-与非式变换）

### 3.4 常用组合逻辑功能模块

**（1）编码器（Encoder）** ：
将输入信号转换为对应的二进制代码输出。n位二进制编码器有2^n个输入。
- **普通编码器**：任一时刻只允许一个输入有效
- **优先编码器**：允许多个输入同时有效，按优先级编码，高优先级覆盖低优先级（常用集成芯片74LS148）

**（2）译码器（Decoder）** ：
将输入的二进制代码翻译成对应的输出信号。n线→2^n线译码器。
- **二进制译码器**：将n位代码译成2^n个输出
- **二-十进制译码器**：将8421 BCD码译成10个输出
- **显示译码器**：驱动七段数码管显示数字或字母
- 集成芯片：74LS138（3线-8线译码器）

**（3）数据选择器（Multiplexer, MUX）** ：
从多路输入数据中选择一路输出。n位地址选择2^n路输入。集成芯片：74LS151（8选1）、74LS153（双4选1）。

**（4）数据分配器（Demultiplexer, DEMUX）** ：
将一路输入数据分配到多路输出之一。

**（5）加法器**：
- **半加器**：两个一位二进制数相加，不考虑低位进位
- **全加器**：两个一位二进制数加低位进位，得和与进位
- **并行加法器**：多位同时相加，但存在进位传递延迟（可通过超前进位提高速度）

**（6）数值比较器**：
比较两个二进制数的大小，输出大于、小于、等于三种结果。集成芯片：74LS85（4位比较器）。

### 3.5 组合逻辑电路中的竞争-冒险

**竞争**：信号经不同路径到达同一汇合点时的时间差。**冒险**：竞争导致输出出现尖峰脉冲（毛刺）。

**类型**：
- **功能冒险**：输入信号变化时多个变量同时改变引起的
- **逻辑冒险**：单个输入变量变化时，由于路径延时不同引起的

**消除方法**：
1. 接入滤波电容
2. 引入选通脉冲（避开冒险时间采样）
3. 修改逻辑设计（增加冗余项）


## 第四章 锁存器与触发器

### 4.1 锁存器

**锁存器（Latch）** 是电平触发的存储单元，具有存储0和1的功能。**基本SR锁存器**由两个与非门或或非门交叉耦合构成，有“置0”、“置1”和“保持”三种功能，状态由S和R端控制。**门控SR锁存器**在基本SR基础上增加使能端E，E=1时可根据输入改变状态，E=0时保持。

### 4.2 触发器

**触发器（Flip-Flop）** 是边沿触发的存储单元，仅在时钟边沿（上升沿或下降沿）改变状态。是构成时序逻辑电路的核心部件。

**常见触发器类型与特性**：

| 触发器类型 | 特征方程 | 功能说明 |
|------------|----------|----------|
| **RS触发器** | Q* = S + \bar{R}Q（SR=0约束） | 置0、置1、保持；输入组合R=S=1不允许 |
| **D触发器** | Q* = D | 上升沿（或下降沿）将D端数据存入，应用最广 |
| **JK触发器** | Q* = J\bar{Q} + \bar{K}Q | 功能最全；J=K=0保持，J=K=1翻转 |
| **T触发器** | Q* = \bar{T}Q + T\bar{Q} | T=0保持，T=1翻转 |
| **T'触发器** | Q* = \bar{Q} | 每次时钟到来都翻转（T=1的T触发器） |

**触发方式**：
- **电平触发**：在时钟电平有效期间输入变化影响输出
- **边沿触发**：仅在时钟边沿采样输入，其他时间输出不变（抗干扰能力强，最常用）
- **主从触发**：由主锁存器和从锁存器构成，上升沿采样、下降沿输出（或相反）

**触发器的状态转换描述方法**：特性表、特性方程、状态图、波形图。

**触发器逻辑功能转换**：通过附加电路可实现不同类型间转换。例如：JK→D（将D接J端，\bar{D}接K端）；D→JK（J\bar{Q}+\bar{K}Q作为D输入）。


## 第五章 时序逻辑电路

### 5.1 时序逻辑电路的特点

时序逻辑电路在任一时刻的输出状态**不仅取决于当前输入，还取决于电路原来的状态**（即具有记忆功能）。时序电路由组合逻辑电路和存储电路（触发器）两部分组成。

### 5.2 时序逻辑电路的分类

- **按时钟分**：同步时序电路（所有触发器共用同一时钟）和异步时序电路（各触发器时钟不同步）
- **按输出分**：Mealy型（输出与输入和状态均有关）和Moore型（输出仅与状态有关）

### 5.3 同步时序逻辑电路的分析

**分析步骤**：
1. **写驱动方程**：各触发器输入端的逻辑表达式
2. **写状态方程**：将驱动方程代入触发器特征方程
3. **写输出方程**：输出端逻辑表达式
4. **列状态转换表**：从初态开始，按状态方程依次递推
5. **画状态转换图**：用圆圈表示状态，箭头表示转换方向
6. **画时序波形图**（视题目要求）

### 5.4 同步时序逻辑电路的设计

**设计步骤**：
1. 根据逻辑需求确定状态数，画出状态转换图
2. 状态化简（合并等价状态，减少触发器的使用）
3. 状态编码（为每个状态分配二进制编码）
4. 列状态转换表（含次态和输出）
5. 求驱动方程和输出方程
6. 画逻辑图

### 5.5 常用时序逻辑功能模块

**（1）计数器**：
- **分类**：同步/异步、加法/减法/可逆、二进制/十进制/N进制
- **集成计数器**：74LS161（4位同步二进制计数器）、74LS90（二-五-十进制计数器）
- **任意进制计数器实现方法**：
  - **反馈归零法**（异步清0）：利用计数器的异步清零端，当计数到N时立即清零
  - **反馈置数法**（同步置数）：利用计数器的同步置数端，当计数到N-1时置入初值

**（2）寄存器**：
- **寄存器**：用于暂时存储二进制数据，多位D触发器并行工作（74LS374）
- **移位寄存器**：数据在时钟作用下逐位移动（74LS194）
- **移位寄存器型计数器**：
  - 环形计数器（首尾相接）：n个触发器实现n个状态
  - 扭环计数器（约翰逊计数器，首尾反相接）：n个触发器实现2n个状态

### 5.6 异步时序逻辑电路

**特点**：各触发器的时钟信号不同，有的触发器由外部时钟驱动，有的由其他触发器的输出驱动。

**分析方法**：与同步时序电路类似，但需先判断各触发器的时钟条件——只有收到有效时钟沿的触发器才按状态方程更新状态，否则保持不变。


## 第六章 脉冲波形的产生与整形

### 6.1 555定时器

**555定时器**是广泛应用的集成定时芯片，内含三个5kΩ分压电阻（由此得名）、两个电压比较器、一个RS触发器、一个放电管。

### 6.2 555定时器的三种典型应用

**（1）施密特触发器**：
- **特点**：具有回差特性（正向阈值V_T+与负向阈值V_T-不同）
- **功能**：将缓慢变化的信号整形为边沿陡峭的矩形脉冲
- **应用**：波形整形、消除干扰

**（2）单稳态触发器**：
- **特点**：有一个稳态和一个暂稳态；在外触发信号作用下进入暂稳态，经一定时间后自动返回稳态
- **脉宽计算**：tw ≈ 1.1RC
- **应用**：脉冲延时、脉冲展宽

**（3）多谐振荡器**：
- **特点**：无稳态，自动产生矩形脉冲
- **周期计算**：T ≈ 0.7(R1+2R2)C
- **应用**：产生时钟信号


## 第七章 半导体存储器与可编程逻辑器件

### 7.1 只读存储器（ROM）

**ROM**：数据在正常工作时只能读出不能写入，断电不丢失。

- **掩模ROM**：出厂时已写入，用户不可更改
- **PROM**：用户可一次编程写入
- **EPROM**：可用紫外线擦除后重写
- **EEPROM**：可用电擦除重写

**ROM结构**：地址译码器（固定与阵列）+ 存储单元阵列（可编程或阵列），因此ROM可用来实现任意组合逻辑函数，相当于数据查找表。

### 7.2 随机存取存储器（RAM）

**RAM**：可读可写，断电数据丢失（易失性）。

- **SRAM（静态RAM）**：用触发器存储数据，速度快，无需刷新，容量较小
- **DRAM（动态RAM）**：用电容存储电荷，需周期性刷新，集成度高，容量大

**容量扩展**：位扩展（增加字长）和字扩展（增加字数）。

### 7.3 可编程逻辑器件（PLD）

**PLD**是由用户编程实现逻辑功能的器件，包括PAL、GAL、CPLD、FPGA等。

**FPGA与数字逻辑电路的关系**：数字逻辑电路的理论知识很好地解释了FPGA设计的思想和过程，为设计复杂数字系统奠定基础。


## 第八章 数模与模数转换

### 8.1 D/A转换器（数模转换）

**功能**：将数字量转换为模拟量（电压或电流）。

**主要技术指标**：
- **分辨率**：输入数字量位数N决定的最小输出电压增量 = V_FS/(2^N-1)
- **转换精度**：实际输出与理想输出的偏差
- **建立时间**：输入变化到输出稳定的时间

**常见类型**：权电阻网络DAC、R-2R梯形网络DAC（电阻种类少，便于集成）。

### 8.2 A/D转换器（模数转换）

**功能**：将模拟电压转换为数字量（编码输出）。

**主要技术指标**：
- **分辨率**：输出数字量的位数
- **转换速度**：完成一次转换所需时间
- **量化误差**：量化过程中引入的误差（±1/2LSB）

**常见类型与特点**：
- **逐次逼近型**：速度较快（微秒级），精度适中，应用最广
- **双积分型**：速度慢，精度高，抗干扰能力强
- **并行比较型**：速度最快（纳秒级），但分辨率较低，功耗大
- **Σ-Δ型**：速度较慢，分辨率极高（24位以上），用于高精度测量


## 附录：考试形式与备考建议

### 常见题型分布

根据多所高校大纲，试卷结构通常为：
1. **选择题/填空题**（约40~50分）：考查基本概念
2. **化简题**（约10~20分）：代数法和卡诺图化简
3. **画图题**（约20分）：波形图、状态图
4. **组合逻辑分析题**（约30~40分）：给出电路→写表达式→列真值表→分析功能
5. **组合逻辑设计题**（约30~40分）：给出功能要求→设计最简电路
6. **时序逻辑分析题**（约30~40分）：写出驱动/状态/输出方程→列状态表→画状态图
7. **时序逻辑设计题**（约30~40分）：根据状态转换图→设计计数器/序列发生器等

### 参考书目

2. **《电子技术基础（数字部分）》（第7版）** ，康华光，高等教育出版社——另一主流教材
